# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.

Report suspected vulnerabilities privately through GitHub's vulnerability
reporting in the affected repository:

1. Open the repository's **Security** tab.
2. Choose **Advisories**, then **Report a vulnerability**.
3. Include the affected version or commit, a minimal reproduction, and the
   impact.

If you are unsure which repository is affected, report against the closest one
and we will route it.

Several OTPKI repositories are forks. If the issue also affects unmodified
upstream code, coordinate disclosure with the upstream project as well.
Upstream security contacts are listed in each fork's own security notes.

## Response

We aim to acknowledge reports within a few business days. Fixes are developed
privately and released with credit to reporters unless you ask otherwise.

## Scope

Security fixes target the latest release and `main` of each repository. Older
tags and fork-specific branches are not separately maintained unless a
repository's own security documentation says so.
