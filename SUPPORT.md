# Support

## Questions and help

* Documentation lives at [otpki-docs](https://github.com/otpki/otpki-docs)
  alongside the source for each project.
* Search existing issues in the repository before filing a new one.
* For usage questions, open an issue in the relevant repository and fill out
  the template — environment details matter for PKI and HSM problems.

## Bugs and features

Use the repository's issue templates. A minimal reproduction is the fastest
path to a fix.

## Security

Do not report vulnerabilities publicly. See
[SECURITY.md](https://github.com/otpki/.github/blob/main/SECURITY.md).
